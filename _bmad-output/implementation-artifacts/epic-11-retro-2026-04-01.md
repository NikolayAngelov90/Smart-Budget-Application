## What Didn't Go Well

### 1. Hardcoded Currency Recurred (HIGH finding × 2)
The hardcoded `'EUR'` issue was explicitly identified and fixed as a HIGH finding in Story 11.2. It was written up, acknowledged by the team. Five stories later, Story 11.7 had the identical HIGH finding.

**Root cause:** Documentation alone doesn't prevent recurrence. No automated enforcement (lint rule, test) was added after the 11.2 fix.

### 2. Timezone Bug Reappeared (11.4 → 11.5)
`toISOString()` vs local date components caused a timezone offset bug in `fmt()` in 11.4. The fix was applied in 11.4, then the same issue appeared in a slightly different form in 11.5 deadline date handling.

**Root cause:** No shared timezone-safe date utility — each story re-implemented date formatting independently.

### 3. framer-motion Mock Pattern Undocumented
Story 11.6's `MilestoneOverlay` test required a non-obvious workaround: local `@chakra-ui/react` mock to avoid conflict between the global jest.setup mock and framer-motion initialization. This required significant debugging with no prior documentation to reference.

Two stories require design decisions that Epic 11 surfaced as unknowns:

**12.1 — Anomaly Detection Algorithm:**
- Current spec: "detect unusual patterns" — valid as user intent, insufficient as implementation spec

- Required: ADR defining algorithm approach before story file creation

**12.3 — Real-Time Smart Nudges:**
- "Real-time" is ambiguous in our request/response architecture
- If it means "within the current session on transaction save" → achievable via SWR mutation + toast
- If it means push notifications → infrastructure not available until Epic 15.5
- Required: Clarify scope definition before story file creation

**Recommended:** Stories 12.1 and 12.3 need technical spikes or ADR write-ups as first action before `create-story` runs.

## Key Lessons for Epic 12

5. **Chronic deferrals need formal cut/commit decisions** — carrying them forward dilutes retro credibility
